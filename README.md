# 🎓 Zajel Telegram Bot (جامعة النجاح الوطنية)

[![Python](https://img.shields.io/badge/Python-3.11+-blue.svg)](https://www.python.org/)
[![Telegram Bot API](https://img.shields.io/badge/Telegram%20Bot%20API-python--telegram--bot-blue.svg)](https://python-telegram-bot.org/)
[![License: MIT](https://img.shields.io/badge/License-MIT-green.svg)](LICENSE)

بوت تيليجرام تفاعلي متعدد المستخدمين لطلاب **جامعة النجاح الوطنية (An-Najah National University)** يتيح الوصول الفوري والسريع إلى خدمات بوابة زاجل الأكاديمية ونظام مودل (Moodle) بكل سهولة وأمان.

---

## ✨ المميزات الرئيسية (Features)

- 🕒 **محاضرات اليوم (/today):** معرفة جدول محاضرات اليوم الحالي مرتبة زمنياً، مع رقم القاعة، الحرم الجامعي (قديم/جديد)، والمحاضرات الإلكترونية.
- 📅 **البرنامج الأسبوعي (/schedule):** استعراض الجدول الدراسي الكامل للفصل المسجل وأسماء المحاضرين وعدد الساعات المعتمدة.
- 📜 **كشف العلامات التراكمي (/transcript):** عرض السجل الأكاديمي الشامل مقسماً فصلاً بفصل، مع علامات المساقات، المعدل الفصلي، والمعدل التراكمي.
- ⚠️ **سجل الغيابات (/absences):** متابعة ساعات الغياب المسجلة وحالة الحرمان لكل مساق.
- 🎓 **بوابة مودل بنقرة واحدة (Moodle SSO):** توليد رابط تسجيل دخول تلقائي مشفر ومباشر إلى حساب الطالب على منصة Moodle دون إعادة إدخال كلمة المرور.
- 📢 **الرسائل الهامة:** قراءة التعميمات والإشعارات الرسمية الصادرة من إدارة الجامعة مباشرة.
- 🔄 **تحديث فوري للجلسات:** إدارة ذكية للجلسات وتجديد الاتصال تلقائياً عند انتهاء جلسة خادم زاجل.

---

## 🔒 بنية الأمان والخصوصية (Security Architecture)

صُمم البوت وفق أعلى معايير الخصوصية والأمان لحماية بيانات الطلاب:

1. **تشفير كلمات المرور في قاعدة البيانات:** يتم تشفير كلمات المرور باستخدام خوارزمية **Fernet (AES-128-CBC مع HMAC-SHA256)** قبل تخزينها، ولا يتم تخزين أي كلمة مرور كنص مجرد (Plaintext) نهائياً.
2. **حذف كلمة المرور الفوري من المحادثة:** فور قيام الطالب بإرسال كلمة المرور في المحادثة لتسجيل الدخول، يقوم البوت بحذف الرسالة تلقائياً خلال أجزاء من الثانية لضمان عدم بقائها في سجل المحادثة.
3. **اتصال مشفر وآمن (HTTPS / SSL):** تتم كافة الاتصالات بين خادم البوت وبوابة زاجل الأكاديمية (https://zajeles.najah.edu) وقواعد البيانات السحابية عبر بروتوكولات HTTPS و SSL المشفرة.
4. **عزل الجلسات في الذاكرة:** يتم الاحتفاظ بجلسات الطلاب في ذاكرة التخزين المؤقت (RAM) لفترات محدودة (TTL) لتسريع الاستجابة ثم إعادة تجديدها بشكل آمن.

## 🚀 التشغيل والإعداد المحلي (Local Setup)

### 1. استنساخ المستودع وتثبيت المكتبات
`ash
git clone https://github.com/MohDara/zajel-telegram-bot.git
cd zajel-telegram-bot
pip install -r requirements.txt
`

### 2. إعداد ملف البيئة (.env)
انسخ ملف .env.example إلى .env:
`ash
cp .env.example .env
`

ثم افتح .env واملأ المتغيرات:
`ini
# توكن البوت من BotFather
TELEGRAM_BOT_TOKEN=1234567890:ABCDefGhIJKlmNoPQRsTUVwxyZ

# مفتاح التشفير المتماثل لقاعدة البيانات (Fernet Key)
APP_SECRET_KEY=generate_with_fernet_generate_key

# المعرف الرقمي لمدير البوت (Telegram User ID)
ALLOWED_USER_ID=123456789

# رابط قاعدة البيانات (اختياري - افتراضياً SQLite محلي zajel_users.db)
DATABASE_URL=
`

> **تلميح لتوليد مفتاح APP_SECRET_KEY:**
> `ash
> python -c "from cryptography.fernet import Fernet; print(Fernet.generate_key().decode())"
> `

### 3. تشغيل البوت
`ash
python bot.py
`

## ☁️ النشر السحابي (Deployment on Render / Cloud)

البوت مهيأ للعمل المباشر على منصات الاستضافة السحابية مثل **Render** أو **Railway**:
- **خادم فحص الحالة (Health Check HTTP Server):** يحتوي البوت على خادم HTTP خفيف مدمج يستمع للمنفذ المحدد في PORT لتلبية شروط Web Service المجانية على Render ومنع تعليق الخدمة.
- **قاعدة بيانات سحابية:** يدعم البوت الاتصال بقواعد بيانات **PostgreSQL** السحابية تلقائياً بمجرد تمرير متغير DATABASE_URL.

## 👑 أدوات الإدارة (Admin Commands)

المستخدم المحدد في ALLOWED_USER_ID يمتلك صلاحيات إدارية متقدمة داخل المحادثة:
- /status - تقرير مباشر بعدد الطلاب المسجلين والجلسات النشطة في الذاكرة.
- /users - قائمة بأسماء ومعرفات الطلاب وتواريخ تسجيلهم.
- /broadcast <نص الرسالة> - إرسال إشعار عام فوري لكافة الطلاب المسجلين.
- /clear_cache - تفريغ الذاكرة المؤقتة وإعادة مزامنة كافة الحسابات.
- /delete_user <user_id> - حذف حساب طالب معين من قاعدة البيانات.
- /errors و /logfile - استعراض سجلات الأخطاء والتشغيل لتشخيص أي مشكلات فوراً.
