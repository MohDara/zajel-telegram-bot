# 🎓 Zajel Telegram Bot (جامعة النجاح الوطنية)

بوت تيليجرام شخصي للوصول المباشر والسريع إلى بوابة زاجل الأكاديمية (An-Najah National University) دون الحاجة لتسجيل الدخول في كل مرة.

---

## ✨ المميزات

- 🕒 **محاضرات اليوم (`/today`):** معرفة محاضرات اليوم ومواعيدها والقاعات ومواقعها (وجاهي / إلكتروني) بضغطة زر واحدة.
- 📅 **البرنامج الأسبوعي (`/schedule`):** عرض جدول الفصل الدراسي الكامل وأسماء المدرسين وعدد الساعات المعتمدة.
- 📊 **بطاقة الطالب (`/profile`):** عرض المعدل التراكمي، التخصص، الكلية، والبيانات الأكاديمية.
- ⚠️ **سجل الغيابات (`/absences`):** متابعة ساعات الغياب المسجلة وحالة الحرمان لكل مساق.
- 🔄 **تحديث مباشر (`/refresh`):** تسجيل دخول فوري وجلب أحدث البيانات من زاجل.
- 🔒 **حماية وأمان كامل:** تقييد استخدام البوت لصاحب الحساب فقط عبر المعرف الرقمي (`ALLOWED_USER_ID`).

---

## 🚀 طريقة التشغيل لأول مرة

### 1. إنشاء بوت تيليجرام والحصول على التوكن
1. افتح تطبيق تيليجرام وابحث عن الحساب الرسمي: **[@BotFather](https://t.me/BotFather)**.
2. أرسل الأمر `/newbot`.
3. اختر اسماً للبوت (مثلاً: `Zajel Portal`).
4. اختر اسم مستخدم للبوت ينتهي بـ `bot` (مثلاً: `my_zajel_assistant_bot`).
5. سيعطيك BotFather رمز التوكن (API Token) الخاص بالبوت، شكله مثل:
   `7123456789:AAHKl...`

### 2. إضافة التوكن في ملف الإعدادات `.env`
افتح ملف `.env` في هذا المجلد وضع التوكن الخاص بك:
```ini
ZAJEL_USER=12000000
ZAJEL_PASS=YOUR_PASSWORD
TELEGRAM_BOT_TOKEN=ضع_التوكن_هنا
ALLOWED_USER_ID=
```

### 3. تشغيل البوت
شغّل البوت من منفذ الأوامر (PowerShell أو CMD):
```bash
python bot.py
```

### 4. حماية البوت بمعرف التيليجرام الخاص بك
1. ادخل إلى البوت على تيليجرام واضغط `/start`.
2. سيظهر لك البوت رقم معرفك الرقمي (`user id`) في رسالة الترحيب.
3. انسخ هذا الرقم وضعه في ملف `.env`:
   ```ini
   ALLOWED_USER_ID=123456789
   ```
4. أعد تشغيل البوت. الآن البوت محمي بنسبة 100% ولا يمكن لأي شخص آخر الوصول لمعلوماتك!

## 📁 ملفات المشروع

- `zajel_client.py`: العميل البرمجي الذي يتعامل مع مصادقة خادم Tomcat وجلب الجداول والمعدل.
- `formatter.py`: قالب الرسائل والتنسيق باللغة العربية مع الإيموجي المناسبة للهواتف.
- `bot.py`: التطبيق الرئيسي للبوت والتفاعل مع أوامر وتفاعلات المستخدم.
- `test_all.py`: اختبارات شاملة للتأكد من اتصال وسرعة استجابة زاجل.
- `.env`: ملف الأسرار (كلمة المرور وتوكن البوت).
